#  Car Hub – Full-Featured E-Commerce Platform for Car Rentals & Purchases

Car Hub is a complete e-commerce web application for car rental and purchase, offering users a seamless experience from browsing to booking or buying cars, with integrated Stripe payment gateway.

# Features
🔐 Secure Authentication & Authorization

ASP.NET Core Identity for user accounts and role management.

Role-based access: Admin & Regular User.

🚘 Dynamic Car Listings

View all available cars with filtering by category (rent/buy), brand, price, and availability.

Each car includes a full detail page with specifications, photos, and availability status.

📅 Car Rental System

Users can book cars for specific dates.

Availability is checked in real-time.

Booking history is available per user.

🛒 Online Car Purchase

Complete e-commerce flow for buying cars directly.

Order history, confirmation messages, and payment receipts.

💳 Stripe Payment Integration

Users can pay securely via Stripe (rental or full purchase).

Secure token-based payments.

Stripe webhooks to confirm transactions.

📈 Admin Dashboard

Manage cars (Add/Edit/Delete), track bookings and sales.

Admin analytics panel to monitor platform activity.

💬 Notifications & Confirmations

Email confirmations for successful bookings or purchases.

Payment invoice after each transaction.

💻 Responsive & Modern UI

Built with Bootstrap 5.3 for a fully responsive design.

Optimized for desktop, tablet, and mobile devices.


# Tech Stack
Frontend: Angular 
Backend: ASP.NET Core Web API
Database: SQL Server
ORM: Entity Framework Core
Payment: Stripe API
